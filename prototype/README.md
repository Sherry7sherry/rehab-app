# FlowMove Clickable Prototype

This is a lightweight mobile-first PWA prototype for validating the FlowMove MVP user journey.

## How To Run

From this directory:

```bash
python3 -m http.server 4173
```

Open:

```text
http://127.0.0.1:4173
```

## Current Coverage

The prototype includes:

- Welcome
- Goal Selection
- Postpartum Screening
- Corrective Pilates Screening
- Training Preferences
- Camera Setup
- Baseline Assessment Intro
- Mock Movement Assessment
- Movement Profile Result
- Recommended Plan Preview
- Today
- Session Preview
- Workout Player
- Session Complete
- Post-Session Report
- Progress
- Programs
- Profile
- Safety Warning preview

## Prototype Notes

- No backend is connected.
- No real camera permission is requested yet.
- No real pose detection is running yet.
- Assessment, scoring, recommendation, and report content use mock logic.
- The goal is to validate product flow, mobile layout, and user experience before building the full Next.js PWA.
